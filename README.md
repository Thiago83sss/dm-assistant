# ⚔️ Asistente del DM - D&D 5e

Herramienta para Dungeon Masters: bestiario, generador de botín y bandeja de dados.


📱 **APK Android:** ver [Releases](https://github.com/Thiago83sss/dm-assistant/releases)

## Tecnologías
React · Vite · JavaScript · CSS · CapacitorJS · [D&D 5e API](https://www.dnd5eapi.co/api/)

## Módulos
- **Bestiario:** búsqueda y estadísticas de monstruos.
- **Botín:** recompensas aleatorias según el nivel de desafío.
- **Dados:** d4, d6, d8, d10, d12, d20 y d100.

## Instalación local
npm install
npm run dev
